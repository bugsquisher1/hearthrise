      Help

      Open: "Open .js" and pick a file from src/data/world/maps/. Or "New map".
      Edit: pick a tool on the left. Brush/Rect paint the selected legend char. Object: click empty tile to place, drag to move, click to select, Delete key removes. Building: drag a rect on empty ground; drag inside a selected building to move, drag its bottom-right corner to resize; Door tool clicks an edge tile to toggle a door. Station/Exit/Start/Focus: click to place, drag to move. Ctrl+Z / Ctrl+Y undo/redo.
      Save: "Save .js" downloads a file with the same name. Copy it into src/data/world/maps/, then run node tests/world-core.mjs --hashes and update maskHash.
      Comments inside the object (not the header) are not kept.
