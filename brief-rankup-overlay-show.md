## 4. FIX DESIGN — one seam
src/render/modal-sheet.js, next to topOpen (:37-46), same `isOpen` (:30-35):
```js
/* Layers the census still counts (tests/modal-primitive-census.baseline.json: 6) plus the
   allowlisted full-screen page. Every sheet on the primitive is found by `.hr-scrim`.
   RULE: pointer-events:none reads as closed (the Hearthfind fade, hearthfind.js:314-316). */
var NOT_YET_SHEETS = '.modal, .qm-overlay, .aep-overlay, .hr-gate, #hr-evicted-gate, .hr-room-scrim, #rb-overlay';
function anyOpen(except) {
  var els = document.querySelectorAll('.hr-scrim, ' + NOT_YET_SHEETS);
  for (var i = 0; i < els.length; i++) if (els[i] !== except && isOpen(els[i])) return true;
  return false;
}
window.HearthriseSheet = { topOpen: topOpen, closeTop: closeTop, anyOpen: anyOpen, __notYetSheets: NOT_YET_SHEETS };
```
Why it stays complete: it judges what is painted (display, visibility, pointer-events, a box), never how an owner closes (node removal, `.show`, `.open`, inline display), so the stuck-open case cannot come back for any surface; `.hr-scrim` covers every sheet on the primitive (welcome-back legacy.js:13664, ach/best, acq via legacy.css:2014 comment, daily :442, rank-up :1029, KO death-sheet.js:1232, name modal identity.js:1137, post-signup :26, What's New welcome-modal.js:99, beta banner :80, dungeon run dungeons.js:818). The FTUE tour root is `pointer-events:none` (ftue.js:209) so anyOpen deliberately does not see it; each caller keeps its own one-token FTUE clause (below), because "tour up from the moment its root builds" (identity.js:1583-1585, b224) and "a hidden tour card must not block What's New" (farm-and-profile.js:1374-1375, b223) are different precedence rules that must not be unified here.

Move the `if (anotherModalUp()) return;` at :1086 INSIDE the try at :1087 so a throw (seam missing) is swallowed and retried next tick, never escaping setInterval; state in the code comment that a missing seam fails CLOSED for that tick.
