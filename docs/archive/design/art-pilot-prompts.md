# Hearthfire Pilot — 13 prompts before the 600

**REVISED 2026-08-16 — all 13 prompts below were re-assembled with the re-cut production wrapper**
(`art-direction-picker.md` §0), because Recraft's generation endpoint caps a prompt at **1000
characters** and the original versions of these ran 1008–1665. The originals are in git history.
Run them with the items/monsters `--style-id` (§0.10): the wrapper no longer describes brushwork
because the style anchor carries it.
Download each as PNG **with transparent background**, named EXACTLY as shown (snake_case, case-exact).
Drop them in a folder and hand them to Claude — they get wired into a branch of the real game
and screenshotted on the live screens (inventory, combat, shop, bestiary) before the full batch runs.

**Coverage logic:** 2 gathering mats + 2 weapons (one iron = the metal fix test, one bronze = the
tier-colour test, because bronze-tier gear is SUPPOSED to be warm), 2 foods, 2 armours (one metal,
one leather control), 5 monsters (tutorial rat, the frost hook, the warm-subject test, the darkest
boss, an antlered boss for complexity).
