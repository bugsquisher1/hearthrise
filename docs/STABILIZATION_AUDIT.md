# Hearthrise — Stabilization Audit (the bug ledger)

Working document for the 24-hour stabilization / release-engineering mission (started 2026-09-04).
One row per issue. **Status:** 🔴 open · 🔧 fix in flight · ✅ fixed+verified · 🧪 audit finding, not yet reproduced · 🧊 backlog.
Loop: INVESTIGATE → REPRODUCE → ROOT-CAUSE → FIX (kill the class) → TEST → PLAYTEST → REGRESSION → COMMIT → CONTINUE.
Rules that bind this mission: CLAUDE.md (one writer on main, agents in worktrees, every fix ships with a test, security signs money/state surfaces, play-gate + visual gate for releases, bump lockstep) plus: **a release is green only when local `run-smoke --ci` AND the GitHub run on the release commit are green.**

## System map (2026-09-04)
- **Server-authoritative (SECURITY DEFINER RPCs via hr_apply / hr-accrue edge):** gold, gems, marks, inventory (MERGE on prod, not absolute), skills/XP, equipment, rooms, workers, farm, companions, traits, property rungs, hero slots, bounties, claims, market, kills (`hr_credit_kills`), attended combat XP (`hr_credit_combat_xp`), away accrual (`computeAccrual`), auto-eat settings, combat style. Projection = `hr_state_of`.
- **Client residue (self-only, forgeable, display cache):** `player_state.client_state` — RESIDUE_FIELDS (src/net/client-state.js). Persistence is an ALLOWLIST (record ∪ residue ∪ reconcile mechanisms ∪ NO_SYNC); BLOB_RETIRED=true.
- **Hybrid / dangerous:** attended combat loot + food (client predicts, server re-sims unattended — SA-001); property tier (residue vs record — SA-002); dungeon scrip/loot/QM (client-minted — SA-015); gem cosmetics/themes/bank space (client debit, no verb — SA-009); G.bank counters (SA-010); companion XP writer (SA-017); Farmer's Deed / bury bones / key+token consumption (SA-018..020).
