# art/inbox: Tyler's PixelLab drop folder

Put PixelLab exports here, named `<set>__<id>.png` (animations: `<set>__<id>__<clip>_<dir>.png`), each with a `.txt` log next to it (tool, settings, prompt, reference, seed). Push to a branch so Claude can see them.

Claude palette-locks, checks and moves accepted files into `art/world/<set>/` or `assets/icons-bundle/pixel/items/`. Nothing here is loaded by the game. Rules: `docs/HEARTHRISE_ART_BIBLE.md` §6 and §8.
