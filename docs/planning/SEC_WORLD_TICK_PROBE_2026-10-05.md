**Before the first COMBAT read counts (M4, not this apply):**
- (a) Score a direction field only when it has ≥12 non-tied probes; below that it reads INSUFFICIENT, never FAIL. Zero-death probes must tie on ticks, so as written a correct engine reads red. This clarifies my ruling.
- (b) PB-2 pins the shipped shadow carrier at −13.6 % ticks (no max_hp), against a green armed-equivalent model. The carrier must carry max_hp. A replay test must also chain windows through hr_apply/hr_state_of against the carrier, byte-identical, because the probe measures the shadow composition, not the armed one.
- (c) The author's 4 min/resume detection floor is acceptable for a statistical probe. It is **not** acceptable as the only resume guard. About 0.9 deaths/h × 4 min ≈ 6 % of combat time, which sits inside the ±10 % band and, if it ran in the over-pay direction, would inflate tradeable drops. M4 needs a deterministic resume-alignment invariant: the resume instant equals the carried `recovering_until`, exactly, attended and away, with a one-tick mutant.
