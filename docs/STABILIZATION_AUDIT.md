# Hearthrise — Stabilization Audit (the bug ledger)

Working document for the 24-hour stabilization / release-engineering mission (started 2026-09-04).
One row per issue. **Status:** 🔴 open · 🔧 fix in flight · ✅ fixed+verified · 🧪 audit finding, not yet reproduced · 🧊 backlog.
Loop: INVESTIGATE → REPRODUCE → ROOT-CAUSE → FIX (kill the class) → TEST → PLAYTEST → REGRESSION → COMMIT → CONTINUE.
Rules that bind this mission: CLAUDE.md (one writer on main, agents in worktrees, every fix ships with a test, security signs money/state surfaces, play-gate + visual gate for releases, bump lockstep) plus: **a release is green only when local `run-smoke --ci` AND the GitHub run on the release commit are green.**
