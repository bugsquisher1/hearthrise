## 1. How to read it

- **Class.** Every target is a DESIGN HYPOTHESIS. HARD is used only for the five constraints. SOFT is kept in the schema for the target work that follows.
- **Form.** What the source asked: a rule (a never, an always or an ordering), a range, or a proposal nobody ruled. It is a hint for the next step, never authority.
- **Kind.** old-ruling (a dated ruling of Tyler's, sittings and page picks included), overhaul-book (the book's PROVISIONAL rows and the 50-standards auditor's PROPOSED bands), designer-ruling (D-1 to D-11), or measurement.
- **Reader.** A standing band of `standards.mjs` at 861ae52e3, a named standard (X), a balance guard line (`guard:`), a printed table (`table:`), or MISSING. The check refuses a reader that does not exist, a dropped or retired band, and a candidate graded only on report-only bands. Planned readers stand in for a MISSING one and the summary says when they land.
- **Evidence words.** MEASURED carries its run. R0 is run 44920906999, R2 is 44925664434, R4 is 44928035806, the replay is 44948522187 and D-3's Run A is 44950722457. COMPUTED is arithmetic on named rows. PROJECTED is past the built content.
