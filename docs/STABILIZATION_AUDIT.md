One row per issue. **Status:** 🔴 open · 🔧 fix in flight · ✅ fixed+verified · 🧪 audit finding, not yet reproduced · 🧊 backlog.
Loop: INVESTIGATE → REPRODUCE → ROOT-CAUSE → FIX (kill the class) → TEST → PLAYTEST → REGRESSION → COMMIT → CONTINUE.

Projection = `hr_state_of`.
- **Client residue (self-only, forgeable, display cache):** `player_state.client_state` — RESIDUE_FIELDS (src/net/client-state.js). Persistence is an ALLOWLIST (record ∪ residue ∪ reconcile mechanisms ∪ NO_SYNC); BLOB_RETIRED=true.
- **Hybrid / dangerous:** attended combat loot + food (client predicts, server re-sims unattended — SA-001); property tier (residue vs record — SA-002); dungeon scrip/loot/QM (client-minted — SA-015); gem cosmetics/themes/bank space (client debit, no verb — SA-009); G.bank counters (SA-010); companion XP writer (SA-017); Farmer's Deed / bury bones / key+token consumption (SA-018..020).
